# dsh-access-phone-remote

**把手机变成你电脑的遥控器** —— 消息推送 / 文件传输 / 位置服务。

数据全部留在你自己电脑上，不经过任何第三方。

---

## 装完你会得到什么

在 dsh 里装好之后：

- **一个设置页** —— 看服务状态、启动/停止、拿到手机访问地址
- **一个手机网页** —— 手机浏览器打开就能用
- **可选的功能** —— 位置服务（搜附近/看路线）、APK 客户端

---

## 快速开始

### 第 1 步：装插件

```sh
dsh plugin --profile web add dsh-access-phone-remote
```

### 第 2 步：装服务端

这个插件是**管理壳** —— 服务端本体要另外放：

```sh
git clone <仓库地址> D:\dsh-access-phone-remote
```

### 第 3 步：在 dsh 里配置

打开 **设置 → 插件 → 插件配置 → dsh-access-phone-remote**：

1. **填项目目录**：`D:\dsh-access-phone-remote`
2. **点「保存配置」**
3. **点「启动服务」**

### 第 4 步：手机连上

设置页会显示**手机访问地址**，形如：

```
http://192.168.1.100:3099/?t=xxxxx
```

**手机浏览器打开它，就通了。**

**要在外面也能用？** 装 [Tailscale](https://tailscale.com/)（免费），电脑和手机登同一账号。

## ⚠️ 三个最容易踩的坑

**这三个坑会让你以为"坏了"，其实只是配置问题。**

### 坑 1：Tailscale 抢了 DNS → 手机上不了网

**症状**：手机能 ping 通 IP，但打不开任何**域名**（甚至微信扫不了共享单车）

**解法**：Tailscale 应用里 → **关掉「Use Tailscale DNS」**

**为什么**：手机的 DNS 被设成了 Tailscale 自己（`100.100.100.100`），而它的"上游"也是"系统默认" → 死循环。

### 坑 2：位置偏 500 米

**症状**：地图上的位置跟实际差几百米

**原因**：手机 GPS 给的是 **WGS84**，国内地图用 **GCJ02**（火星坐标）。直接混用就差 500 米。

**这个项目已经处理了** —— 但如果你改代码，务必注意。

### 坑 3：`.bat` 用 LF 换行 → 启动脚本静默失效

**症状**：开机自启配了，但从来没生效过

**原因**：Windows 的 `.bat` 必须是 **CRLF** 换行。LF 换行会让 `cmd.exe` 解析错乱。

**解法**：转成 CRLF（VS Code 右下角可以切）。

## 这个插件本身能干什么

装完之后，dsh 设置页里有：

| 功能 | 说明 |
|---|---|
| **看状态** | 服务在跑吗、端口、目录 |
| **启动/停止/重启** | 一键 |
| **看地址** | 手机访问 URL（含 token） |
| **改配置** | 项目目录、端口 |
| **复制诊断信息** | 一键生成给 AI 的报告 |

## 服务端能干什么

| 接口 | 用途 |
|---|---|
| `/api/push` | 推送消息到手机 |
| `/api/inbox` | 拉取消息 |
| `/api/events` | SSE 实时流 |
| `/api/file` | 文件下载 |
| `/api/upload` | 文件上传 |
| `/api/poi` | 搜附近（需高德 key） |
| `/api/route` | 路线规划（需高德 key） |
| `/api/run` | 执行预设指令（白名单） |

**零 npm 依赖** —— 只用 Node 内置模块。

---

## 安全性

- **服务只在你自己的网络里**（局域网 / Tailscale）
- **Token 鉴权**（首次启动自动生成）
- **指令白名单** —— 只能执行预设动作，**不能执行任意命令**
- **文件路径白名单** + 防路径穿越

**⚠️ 不要暴露到公网。**
