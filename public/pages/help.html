帮助

连不上？很慢？收不到推送？先看这里
手机打不开页面

按顺序查三步：

  1. 服务在跑吗 —— 电脑上执行 node src/doctor.js， 看「端口」那项是不是「服务正在运行」。
  2. 手机能通吗 —— 要先确认手机和电脑在同一个网络 （同一个 WiFi，或都装了 Tailscale 并登录同一账号）。
  3. 防火墙拦了吗 —— 特征很明显：局域网打不开但 Tailscale 能开， 基本就是防火墙。Windows 上以管理员运行： 
    netsh advfirewall firewall add rule name="dsj" dir=in action=allow protocol=TCP localport=3099

提示：启动服务时终端会打印所有可用地址， 挑局域网那个试。带 (virtual) 标记的是虚拟网卡，手机连不上。

能连上，但很慢

先分清是哪种慢：

  • 刚切换网络（WiFi ↔ 4G） —— 正常。 头 1~2 分钟会走中继，然后才打洞直连。等一下再试。
  • 一直慢 —— 移动网络本来就比局域网慢很多 （实测局域网 19.9 MB/s，移动网 0.7 MB/s）。
  • 传大量小文件慢 —— 每个文件都有多次往返开销。 可以先打包再传。

判断走的是不是直连：tailscale ping <对方IP>
显示 via DERP = 走中继（慢）；显示 via <IP>:<端口> = 直连（快）。

过一会儿就连不上了

最常见的原因：手机把后台进程杀了。

Android 上要做的：

  • 把 Tailscale（或本 App）加进电池优化白名单
  • 开启常驻 VPN（Tailscale 设置里）
  • 小米 / HyperOS 还要额外允许自启动

如果用的是 Tailscale，先看电脑上 tailscale status 是不是 stopped。

收不到推送
  1. 页面收到了吗 —— 打开页面看「消息」区有没有。有 → 是通知的问题；没有 → 是服务端的问题。
  2. 通知权限 —— Android 13 以上必须主动允许通知， 光装 App 不够。去系统设置 → 应用 → 通知，手动打开。
  3. App 退到后台就收不到 —— 这是已知问题（SSE 长连接会静默变死）。 当前版本已加读超时自动重连，最坏情况会瞎 15 分钟。
位置不准 / 偏了几百米

这是坐标系问题，不是 bug。

手机 GPS 给的是 WGS84，国内地图（高德/百度）用 GCJ02（火星坐标）。 两者直接混用会偏 约 500 米。

本服务在定位时已经做了转换。如果你是自己改代码遇到的， 检查有没有在调地图接口前做 WGS84→GCJ02 转换。

位置功能完全用不了

需要高德 key（位置功能区不填 key 就不工作）：

  1. 去 lbs.amap.com 注册
  2. 创建应用，申请两个 key： Web 服务（后端用）和 Web 端 JS API（页面嵌地图用）
  3. 填进 config.json 的 amap 段

如果页面报 INVALID_USER_KEY：JS API key 有 referer 限制， 去高德控制台把域名加白，或留空（= 不限）。

传文件报错
  • 「路径不在白名单」 —— 允许的目录在 config.json 的 allowDirs 里。想读别的目录就往里加。
  • 「文件太大」 —— 上传上限 20MB，读取上限 2MB。
  • 可执行文件被拒 —— 这是故意的（安全策略）， .exe/.bat/.ps1/.apk 这些不让通过。
开机不会自动启动

最常见的坑：如果你写了个 .bat 来启动， 它必须是 CRLF 换行（不是 LF）。用 LF 的话 cmd.exe 会解析错乱， 整个脚本静默失效 —— 看起来配了，其实从没跑过。

另外：不要用「后台运行」的方式起服务（比如直接 start 或 nohup）， 那样起的进程会随终端关闭而死。

Windows 上正确做法是计划任务：

schtasks /Create /TN "dsj-open" /TR "node D:\path\to\src\server.js" /SC ONLOGON /RL HIGHEST /F
我想加个自己的按钮 / 接口

加按钮：改 src/commands.js，往 COMMANDS 数组里加一项。 前端会自动渲染出来，不用改页面。

加接口：在 src/routes/ 下选一个文件（或新建）， 写 register(server, config)，然后在 server.js 里挂载。

完整说明见项目里的 docs/FOR-AI-EXTEND.md （那份是写给 AI 助手看的，直接丢给你的 AI 让它做也行）。
